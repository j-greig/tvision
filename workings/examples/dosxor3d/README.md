XOR 3D Cube for DOS
=======================

This program compiles with Turbo C 2.01 for MS DOS machines. It
displays a rotating cube. It uses only fixed point maths, except for
initializing the sine-table, which requires the sin() function.  The
cube is drawn using XOR functions so the drawing itself is invisible
when the animation is stopped with the key 'Q' and is visible again
when hitting the 'E' key. The animation is only visible due to the
persistence of vision of the human brain.
