# NOTATIONS.21 COMPOSER DATABASE

This database contains 50 composers from Theresa Sauer's **Notations.21** anthology, honouring and extending John Cage's original _Notations_. Each entry includes biographical context and notation approach.

**Usage**: The music-notation skill can grep or read specific entries when generating notation inspired by these composers.

---

## 01. MARK APPLEBAUM

**Bio**: California-based composer, Stanford professor, creates experimental instruments, known for unconventional performance art, blurs boundaries between sonic/visual disciplines.

**Notation**: Developed "metaphysical notation" using abstract symbolic gestures divorced from specific sounds. Creates hand-drawn pictographic movement scores demanding physical choreography from performers. Pieces like "Tlön" transform musicians into gestural actors following cryptic symbolic maps.

---

## 02. EARLE BROWN

**Bio**: American composer (1926-2002), pioneered open-form music, member NY School alongside Cage, influenced by Calder mobiles, jazz improvisation background.

**Notation**: Created "proportional notation" eschewing traditional metrics for spatial-temporal relationships. Composed "December 1952" featuring abstract horizontal/vertical lines forming movable musical mobiles. Scores function as "sonic activators" rather than fixed instructions, allowing conductor-controlled spontaneous interpretation.

---

## 03. CORNELIUS CARDEW

**Bio**: British experimental composer (1936-1981), Stockhausen assistant, founded Scratch Orchestra, later rejected avant-garde for political music.

**Notation**: Created 193-page "Treatise" (1963-67) containing abstract geometric symbols without performance instructions. Developed graphic systems embracing indeterminacy while paradoxically demanding precise interpretation. Later works used simplified notation empowering non-musicians within political-musical collectives.

---

## 04. SYLVANO BUSSOTTI

**Bio**: Italian composer-artist-designer (1931-2021), LGBTQ+ pioneer, multi-disciplinary creator, known for visual/theatrical compositions, studied with Max Deutsch.

**Notation**: Transformed scores into visual artworks using dense calligraphic explosions resembling abstract expressionism. Created "Five Piano Pieces for David Tudor" incorporating gestural marks, symbols, scattered notes creating visual poetry. Developed notational language merging theatrical directions, erotic imagery, musical instructions into unified visual field.

---

## 05. ROBERT MORAN

**Bio**: American minimalist composer (b.1937), organized first city-scale simultaneous performance events, collaborated with Philip Glass.

**Notation**: Designs circular/spiral scores requiring performers read from center outward. Creates graphic notation systems for large-scale urban performances incorporating hundreds of musicians. Employs environmental scoring techniques mapping sonic relationships through spatial diagrams rather than traditional notation.

## 06. CHIYOKO SZLAVNICS

Creates visualization systems mapping exact microtonal relationships through measured angles on graph paper. Scores function simultaneously as visual artworks and precise performance instructions for extended-tone compositions.

## 12. JOHN CAGE

**Bio**: American composer-philosopher (1912-1992), pioneered indeterminacy, prepared piano, chance operations, Zen influence, mushroom expert.
