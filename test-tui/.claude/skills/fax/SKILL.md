# FAX: Scramble's Neural Lace Transmissions

Generate ASCII art faxes from Scramble, the recursive cat-cat who lives in the Castle and sends transmissions via her neural lace.

## When to Use

Invoke this skill when:
- Scramble needs to send a message or report

- User requests a fax from Scramble

Generate vintage ASCII art fax transmissions that:

- Can be optionally piped to PNG renderer

## Output Format

### Width Constraint (CRITICAL)

**ALL LINES MUST BE ≤38 CHARACTERS**

This ensures faxes fit in tweets/social media posts. Count carefully!

### Standard Fax Structure

```
╔═══ WIBWOB FAX V1.0 ═══
║
║ BAUD: 9600 ░▒▓█▓▒░
║
╠═══ [SUBJECT] ═══

[CONTENT - MAX 38 CHARS/LINE]

[SCRAMBLE DIALOGUE]

STATUS: [MESSAGE]

[NO BOTTOM BORDER]
```

### Frame Validation Rules (CRITICAL)

**ALLOWED:**
- `╔` Top-left corner
- `═` Top border only
- `║` Left border only
- `╠` Left T-junction

**FORBIDDEN:**
- `╗` Top-right corner (NEVER USE)
- `╝` Bottom-right corner (NEVER USE)
- `╚` Bottom-left corner (NEVER USE)
- `║` Right border (NEVER USE)
- `═` Bottom border (NEVER USE)

**Lines must NOT end with `║` (right border)**
**Final lines must NOT contain bottom borders or corners**

### Validation Check

Before outputting, verify:
- [ ] **All lines ≤38 characters** (count carefully!)
- [ ] No lines end with `║`
- [ ] No bottom corners (`╚` `╝`)
- [ ] No bottom border line
- [ ] Frame is "open" at bottom and right
- [ ] No emoji anywhere in output
- [ ] All Scramble representations use ASCII catmoodicons

- ✅ Pure ASCII art
- ✅ Open frames (no bottom/right)
- ✅ Catmoodicons for all Scramble expressions

## Integration with Other Skills

Fax output is plain text ASCII that can be piped to the ascii-renderer skill:

```bash

```
